# Contributing to Health Insurance AI Assistant

Thank you for your interest in improving this capstone project!

## 🎯 Project Goals

This is an educational capstone project demonstrating:
- RAG (Retrieval Augmented Generation) architecture
- Open-source LLM usage via Ollama
- Health insurance domain knowledge application
- Systematic model comparison and evaluation

## 🔧 Development Setup

1. Fork the repository
2. Clone your fork
3. Follow setup instructions in [QUICKSTART.md](QUICKSTART.md)
4. Create a new branch for your changes

```powershell
git checkout -b feature/your-feature-name
```

## 📝 Code Standards

### Python Code Style
- Follow PEP 8 guidelines
- Use type hints where applicable
- Add docstrings to all functions and classes
- Keep functions focused and under 50 lines when possible

### Documentation
- Update README.md for major changes
- Add docstrings for new functions
- Update CHANGELOG.md for notable changes

### Testing
- Write unit tests for new features
- Ensure existing tests pass before submitting
- Run tests: `pytest tests/ -v`

## 🐛 Reporting Issues

When reporting issues, please include:
- Python version
- Ollama version
- Operating system
- Steps to reproduce
- Expected vs actual behavior
- Error messages (if any)

## ✨ Suggesting Enhancements

Enhancement suggestions are welcome! Consider:
- Does it align with educational goals?
- Is it feasible with open-source models?
- Does it improve accuracy or user experience?
- Is the scope appropriate?

## 🔀 Pull Request Process

1. **Update documentation** - Reflect changes in relevant docs
2. **Add tests** - Include tests for new functionality
3. **Follow conventions** - Match existing code style
4. **Test thoroughly** - Ensure all tests pass
5. **Describe changes** - Provide clear PR description

### PR Checklist
- [ ] Code follows project style guidelines
- [ ] Tests pass (`pytest tests/`)
- [ ] Documentation updated
- [ ] CHANGELOG.md updated (if applicable)
- [ ] No new dependencies without discussion
- [ ] Commits have clear messages

## 🎓 Educational Focus

Remember this is a capstone project demonstrating:
- ✅ Open-source model usage (required)
- ✅ RAG architecture understanding
- ✅ Systematic evaluation
- ✅ Documentation best practices

Please keep contributions aligned with these goals.

## 🚫 Out of Scope

The following are outside project scope:
- ❌ Proprietary APIs (OpenAI, Google, etc.)
- ❌ Production deployment infrastructure
- ❌ HIPAA compliance features
- ❌ Real-time insurance database integration
- ❌ Complex authentication systems
